pre-design

Structure first.
Visual style next.

Before moving to the final design, I build a preliminary system: page logic, user scenarios, layout grid, visual direction, and a set of rules that allow the project to grow further.

  1. 01 / objective

    task

    What needs to be launched, updated, or simplified.

  2. 02 / structure

    structure

    Pages, sections, user journeys, categories, and touchpoints.

  3. 03 / direction

    direction

    Typography, layout grid, mood, visual language, and the first design principles.

  4. 04 / system

    system

    A foundation from which a website, brand, catalogue, packaging, advertising campaign, or brand book can grow.
